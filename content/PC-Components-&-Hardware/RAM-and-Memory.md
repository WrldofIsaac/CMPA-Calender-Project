# RAM and Memory

**RAM** (Random Access Memory) is your computer's **short-term memory**. It acts as a fast digital workspace or workbench where your processor (CPU) temporarily holds the data and instructions it needs _right now_ for open apps and active tasks.

![[computer-ram.jpg]]
## How RAM affects gaming

A game needs memory for things such as maps, textures, characters, and other information it uses while running. If a PC doesn't have enough RAM for games and other programs, it will slow down and stutter your system. Having sufficient RAM makes it easier for you to multitask and play game. 

### Capacity, speed, and generations

RAM is measured by gigabytes (GB). The more memory you have the more it can help you run demanding game titles, edit videos, or even multitask. However just because you add more RAM to your system, doesn't mean it automatically increase frame rate.  RAM also has a speed rating, and newer generations such as DDR5 are not interchangeable with older DDR4 memory.

## What should you check before buying?

1. Check the motherboard requirements to see which RAM generation it supports.
2. Decide how much capacity makes sense for the games and applications you use.
3. Compare supported memory speeds rather than assuming the highest speed will work.
4. If buying a kit with multiple sticks, follow the motherboards' manual for the recommended slots.

Many gaming builds only use 2 RAM sticks so they can run dual-channel mode.

## Final thoughts

RAM is only one part of performance. The [[CPUs-and-Processors|CPU]] works with system memory, while the [[Graphics-Cards-GPUs|GPU]] has its own video memory called VRAM. These are different kinds of memory and should not be confused.
