# CPUs & Processors

The CPU also known as the central processing unit, is often described as the brain of a computer. It the main hardware component in a computer or smart device that executes program instructions and coordinates system operations. When you think about building a gaming PC, the graphics card is usually hardware that gets the most attention, but the CPU still matters as well. A powerful GPU can still be bottlenecked (held back) if the CPU cannot keep up with it.

## What does a CPU do?

A CPU primary function is to retrieve, decode, and execute program instructions to process data. So when you are gaming, it helps with things like character movement, physics, graphics and other background tasks. It also helps multitask between many different applications at the same time.

### Cores, Threads, and Clock speed

A CPU has cores that execute instructions, perform calculations, and handle tasks simultaneously. Having multiple cores lets your computer run several programs or split heavy workloads across different parts of the chip at once. Many modern processors also use threads to handle work more efficiently. The more cores you have, the more it will help with multitasking. But also note, ==🟠Just because a CPU have a higher core count, doesn't mean it'll make a game run faster. ==

Clock speed is usually shown in GHz. It pretty much gives an idea of how quickly a processor can perform cycles. But, it shouldn't be the only number you use to compare different CPUs. 

## Choosing a processor for gaming

Before buying a CPU, I would check:

- Whether the CPU comes with the cooler, or if it needs to be purchased separately.
- How well it performs in the games you play.
- Whether the motherboard actually supports the CPU.
- Whether the CPU actually fits in the socket.
- If the price gives you enough wiggle room to get a good GPU.

Making sure that you have a balanced system is better than just spending too much money on one part. The [[Graphics-Cards-GPUs|Graphics Cards/GPUs]] and CPU need to work well together, while the [[RAM-and-Memory|Ram & Memory]] also effects how smoothly your computer handles games and other applications.

> A good gaming PC is not just one expensive part. It is a group of components that work well together.

## Final Thought

I would compare the benchmark stats before choosing a processor. The best CPU for you should fit your budget and cater to your gaming needs.
